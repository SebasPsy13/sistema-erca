### PASO 2: Inicializar Git (3 MINUTOS)

```bash

# Agregar archivos

```

---

### PASO 3: Crear Repositorio en GitHub (1 MINUTO)

1. Abre: https://github.com/new
2. Nombre del repo: `sistema-erca`
3. Descripción: `Sistema de gestión de pacientes ERCA`
4. **Selecciona: Public**
5. Click: "Create repository"

---

### PASO 4: Subir a GitHub (1 MINUTO)

GitHub te mostrará un comando. Cópialo y ejecuta en Terminal:

```bash
git branch -M main
git remote add origin https://github.com/TU_USUARIO/sistema-erca.git
git push -u origin main
```

(Reemplaza `TU_USUARIO` con tu usuario de GitHub)
